Able Player Demos

Able Player with media queries

This demo shows how Able Player behaves when media queries are applied. Resize the browser window or apply media queries like prefers-reduced-motion or prefers-reduced-data to see how sources change.

The supported media queries in this demo include prefers-color-scheme, orientation, and prefers-reduced-motion.

The files used for this demo were sourced from Adrian Roselli's article Media Queries for Accessible Videos, and are used with permission.

When sources are available that would meet multiple conditions, the more complex conditions should be first in the source order. Able Player will load the first matching source, but a source with prefers-reduced-motion will also match on browsers that have additional conditions present.
